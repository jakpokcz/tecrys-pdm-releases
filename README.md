# Tecrys PDM releases

**Tecrys PDM** keeps a team's Tecrys files in a shared vault: check out, check in, versions,
lifecycle states, references and bills of materials. It works with a vault served by
[Tecrys Vault](https://github.com/jakpokcz/tecrys-vault-releases). It includes the `tecrys-pdm`
command line: on the Mac inside the app (`Tecrys PDM.app/Contents/MacOS`), in Windows next to it.

- **Download**: see [Releases](../../releases). Mac (Apple Silicon, macOS 14+): the `.dmg`;
  Windows: `windows-x64.exe` (most PCs) or `windows-arm64.exe` (ARM PCs).
- **First start**: Tecrys PDM is not signed by Apple or Microsoft. On the Mac open System Settings ▸
  Privacy & Security ▸ Open Anyway; in Windows click More info ▸ Run anyway. Later versions arrive
  through *Check for Updates…* in the app and need no approval.
- Tecrys PDM is free to download; it is not open source.

The `appcast-*.xml` files are the update feeds (signed with the Tecrys update key); don't edit them by hand.
